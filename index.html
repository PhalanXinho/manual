Introduction

Introduction

This manual guides users through installing Eclipse Kura on a Raspberry Pi and connecting it to Cloud Multiplatform H2Train through Eclipse Kapua for remote device maintenance.

Purpose and Scope

The manual covers the prerequisites, installation, and connection settings used in the project's current implementation. It provides commands, screenshots, and reference material to support the configuration of a device for maintenance operations, including application updates.

Intended Audience

The intended audience is project participants and technical staff responsible for device setup. Readers should be familiar with basic Linux terminal commands, network settings, and the use of sudo for administrative tasks.

Reading Guide

The manual is organized as follows:

Chapter Content
1. System Overview Components, architecture, communication, and access mechanisms.
2. Hardware, Software, and Prerequisites Device requirements and VPN access.
3. Installing Eclipse Kura Java and Kura installation and initial console access.
4. Connecting to Cloud Multiplatform H2Train with Eclipse Kapua Registration and maintenance service configuration.
5. Glossary and Reference Material Definitions, external documentation, and deployment resources.
6. Changelog Revision history and contact details.

Read chapter 1 for the technical background, then follow chapters 2 through 4 in sequence. Consult chapter 5 as needed.

Use the navigation panel to move between chapters and sections. Run commands on the Raspberry Pi unless the procedure specifies otherwise.
