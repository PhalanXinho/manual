# Introduction

This manual guides users through installing Eclipse Kura on a Raspberry Pi and
connecting it to **Cloud Multiplatform H2Train** through Eclipse Kapua for remote
device maintenance.

## Purpose and Scope

The manual covers the prerequisites, installation, and connection settings used
in the project's current implementation. It provides commands, screenshots, and
reference material to support the configuration of a device for maintenance
operations, including application updates.

## Intended Audience

The intended audience is project participants and technical staff responsible
for device setup. Readers should be familiar with basic Linux terminal commands,
network settings, and the use of `sudo` for administrative tasks.
