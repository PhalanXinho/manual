# H2Train Edge-to-Cloud Manual

This manual outlines how to prepare a Raspberry Pi, install and use Eclipse Kura,
and connect the device to **Cloud Multiplatform H2Train** through Eclipse Kapua.

It is intended for users setting up a device for the first time and for operators
responsible for its ongoing configuration and maintenance.

## Documentation Status

The chapters currently provide an initial documentation outline. Their sections
define the topics to develop into procedures, examples, and verification checks.
Deployment-specific values, including supported software versions, cloud
addresses, credentials, and certificates, must be confirmed before completing
the installation and connection instructions.

## Reading Guide

- Start with **System Overview** to understand the components and their roles.
- Follow chapters 2 through 6 for the path from prerequisites to cloud connection.
- Use **Data Collection and Connection Validation** to plan an end-to-end check.
- Consult the final chapters for ongoing operation, troubleshooting, and references.

The chapter index is maintained in [SUMMARY.md](SUMMARY.md). Each chapter is a
Markdown file that HonKit uses to build the manual.
