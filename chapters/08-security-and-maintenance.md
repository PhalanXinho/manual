# 8. Security and Maintenance

Outline the practices needed to keep the device and its cloud connection secure
and maintainable after initial setup.

## 8.1 Local and Cloud Access Management

Cover administrator access, credential handling, and permissions appropriate to
each operator's role.

## 8.2 Network and Transport Security

Document the approved exposure of administration interfaces and the secure
transport settings required for cloud communication.

## 8.3 Credential and Certificate Lifecycle

Describe renewal, rotation, revocation, and checks for certificate expiry.

## 8.4 Configuration Backups and Restore Procedures

Define what to back up, where to store it, and how to verify restoration.

## 8.5 Software Updates and Rollback

Outline compatibility checks, update preparation, post-update validation, and
the recovery path if an update fails.

## 8.6 Routine Health Checks

Define checks for storage, service health, connectivity, logs, and data delivery.
